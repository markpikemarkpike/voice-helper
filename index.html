Voice Helper

Demo

This is a demo with a made-up conversation. Tap Next line, then tap a reply. Set it up in Settings and it listens to the real conversation and suggests replies that fit.

Where replies come from

You use your own Anthropic API key, and you pay Anthropic for what you use. Make a key just for this, on an account with only a little credit and automatic top-ups off, at platform.claude.com.

Any service or program that answers in the common "chat completions" format. That includes free models running on this computer, which need no key. Only type an address you trust.

Left off, the key is forgotten when you close the page. Turned on, it is kept in this browser, where other pages at the same web address could read it.

Smaller models answer faster and cost less. In a conversation, speed matters most.

Please read

Tell people the device is listening. Once you start it, the microphone stays on for the whole conversation. It is covered only while the device is speaking. Your browser turns what it hears into text, and its maker may do that on its own servers. The words then go to Claude, or to the address you chose under Other, to get replies. What those companies do with what they receive is up to their own terms and privacy policies.

This page never saves the conversation. It is gone when you close the page. Each thing it hears sends one request. If nobody taps for a while it keeps listening but stops asking for replies, so a television cannot run up a bill.

This is a hobby project. It has not been reviewed, cleared or tested as a medical device. The replies are guesses, so read before you tap.

Use your own voice

If you banked your voice at ElevenLabs, or had a copy made there from old recordings, replies can be spoken in it. You use your own API key. Make one just for this, limited to text to speech and reading voices, with a credit limit.

Turned on, other pages at the same web address could read it.

Please read

The words of each reply you tap are sent to ElevenLabs, which sends back the sound. That uses credit on your account. If it cannot be reached, the device's voice speaks.

Only use a voice that is yours, or that you have permission to use. This page does not record, copy or keep anyone's voice.

As far as I can tell, Apple's Personal Voice works in apps but not on web pages. This project is not affiliated with or endorsed by ElevenLabs.
